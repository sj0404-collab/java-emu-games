# Heroes Lore: Zero — Unity Engine

J2ME classic RPG rewritten in C# for Unity Engine.

## Features
- Isometric tile-based RPG
- 6 hero classes
- 10 enemy types
- Combat system with skills
- Inventory & equipment
- Virtual D-pad + Gamepad support
- Full Russian localization

## Build
The project builds automatically via GitHub Actions.
APK is available in the Releases section.

## Controls
| Input | Action |
|-------|--------|
| D-pad / Left Stick | Move |
| A / South | Attack |
| B / East | Use Skill |
| M / Start | Menu / Inventory |
| OK / North | Confirm |
| X / West | Cancel |

## Tech
- Unity 2022.3 LTS
- C# (IL2CPP for Android)
- Procedural sprites (no external assets needed)
- Single APK, no OBB
