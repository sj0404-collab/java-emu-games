# Локальный AI для Android

Маленькое нативное Android-приложение с `llama.cpp`. APK **не содержит модель**: пользователь выбирает локальный instruct/chat `.gguf` через системный SAF picker. Файл читается через `/proc/self/fd/<fd>` и не копируется во внутреннее хранилище приложения.

## Возможности и границы

- Android 8.0+ (`minSdk 26`), только `arm64-v8a`;
- профили Auto, обычный диалог, кодинг, D&D/RPG, творчество и точный анализ;
- streaming, остановка, текстовые вложения до 1 МБ и локальный Android TTS;
- системный `RecognizerIntent` с запросом offline recognition (фактическая офлайн-доступность зависит от установленной речевой службы и языкового пакета);
- нет разрешений `INTERNET`, общего storage, камеры или микрофона в manifest; доступ к выбранному документу выдаёт SAF, а распознавание запускается отдельной системной Activity;
- приложение не добавляет фильтр ответов. Ограничения и поведение самих весов модели остаются свойствами выбранного GGUF;
- фото, музыка и видео не притворяются текстовыми возможностями: для них нужны отдельные, загружаемые по требованию specialist-модели, которых в этом компактном APK нет.

Приложение принимает один GGUF до 2 ГБ, но также проверяет оценочный пик native RAM (веса + context/KV + рабочий запас) ниже 1,9 ГБ. Для телефона рекомендуется **Qwen3 0.6B Q4_K_M** (~484 МБ), контекст 2048. Удаление/отключение флешки во время работы с mmap-моделью может аварийно остановить inference.

Архив `.tar.xz` годится для переноса, но его нужно один раз распаковать. Сжатый tar нельзя эффективно mmap-ить и читать с произвольным доступом во время inference.

## Сборка

Закреплённые версии:

- AGP 8.8.2 / Gradle 8.10.2;
- compile/target SDK 35;
- NDK `27.2.12479018`;
- CMake `3.22.1`;
- llama.cpp commit из `llama-version.txt`.

Требуются JDK 17 и Android SDK packages `platforms;android-35`, `build-tools;35.0.0`, `ndk;27.2.12479018`, `cmake;3.22.1`.

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME="$HOME/android-sdk"
bash scripts/build-apk.sh
```

Скрипт скачивает только закреплённый shallow checkout llama.cpp в игнорируемый `android/vendor/`, собирает подписываемый release и кладёт APK с SHA-256 в `artifacts/`.

По умолчанию release подписывается локальным Android debug key, чтобы APK можно было установить. Для собственной release-подписи задайте:

```bash
export LOCAL_AI_KEYSTORE=/absolute/release.jks
export LOCAL_AI_STORE_PASSWORD='...'
export LOCAL_AI_KEY_ALIAS='...'
export LOCAL_AI_KEY_PASSWORD='...'
bash scripts/build-apk.sh
```

Секреты и keystore не должны попадать в Git.

## Импорт модели

1. Скачайте совместимый одиночный instruct/chat GGUF на телефон или USB-флешку.
2. Откройте приложение и нажмите **«Импорт GGUF»**.
3. Выберите context 1024/2048/4096 до загрузки модели.
4. Выберите профиль либо оставьте Auto.
5. При необходимости прикрепите текстовый файл, включите TTS или используйте системный голосовой ввод.

Лицензию модели проверяйте отдельно: лицензия кода приложения не меняет лицензию весов.
